How to play

In Original, type an unused English word containing the letters on the bomb. Press Enter before the fuse burns out. Missing a turn costs one heart.

Chain Word takes the next prompt from the end of the last word. Typing Race asks for an exact match. In Letter Link, type a word of three or more letters along adjacent tiles, using each tile once.

Practice alone or pass the keyboard between up to four players. The last player with a heart wins.
